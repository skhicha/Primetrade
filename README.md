# Primetrade — Trading Sentiment Dashboard

A React dashboard for visualizing trading sentiment data, with CSV-based data import and exportable reports.

## Features
- Interactive charts built with Recharts for sentiment and market data visualization
- CSV data parsing and import via PapaParse
- Export dashboard views to PDF/image via jsPDF and html2canvas
- Component-based React architecture with Jest test coverage

## Tech Stack
React · Recharts · PapaParse · jsPDF · html2canvas · Jest

## Getting Started
```bash
npm install
npm start
```
